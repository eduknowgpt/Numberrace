# The Number Race — Maintained and Extended Version

This repository contains a maintained and extended version of
**The Number Race**, an open-source educational game designed to
support the development of number sense.

The project is based on the original Number Race source code,
distributed under the GNU General Public License version 2.

## About the original project

The Number Race was developed as an educational game for numerical
cognition and mathematics learning.

Original project:
[The Number Race on SourceForge](...)

This repository is not the original upstream repository. It contains
modifications, maintenance work, localization improvements, and new
development based on the original GPL-licensed source code.

## Goals of this repository

The goals of this maintained version include:

- preserving the original functionality of The Number Race;
- modernizing the Java/Maven project structure;
- improving maintainability and compatibility with current development
  environments;
- maintaining the existing language packs;
- adding Brazilian Portuguese support;
- correcting resource and audio-loading issues;
- improving performance and responsiveness;
- enabling future educational and research-oriented extensions.
