## This repository

This repository contains a maintained and modified version of
The Number Race.

Changes include, among others:

- project structure cleanup and Maven reorganization;
- Portuguese (Brazil) localization;
- fixes to language-pack resource loading;
- fixes to localized audio resource handling;
- build and Eclipse development improvements;
- compatibility and maintenance changes;
- ongoing modernization and new functionality.

These modifications do not imply endorsement by the original
authors or maintainers of The Number Race.

See CHANGELOG.md and the Git history for details.
